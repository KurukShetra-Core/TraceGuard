# Contributing to TraceGuard 🛡️

First off, thank you for considering contributing to **TraceGuard**! TraceGuard is an innovative, real-time error tracking and AI-powered diagnostic platform built with the MERN stack (MongoDB, Express, React, Node.js), Vite, and Tailwind CSS.

---

## 🚀 Quick Start & Development Setup

### Prerequisites
* **Node.js**: `v18.0.0` or higher
* **npm**: `v9.0.0` or higher
* **Git**

### Setup Instructions

1. **Fork & Clone the Repository**
   ```bash
   git clone [https://github.com/KurukShetra-Core/TraceGuard.git](https://github.com/KurukShetra-Core/TraceGuard.git)
   cd TraceGuard
   ```

2. **Frontend Setup (React + Vite + Tailwind CSS)**
   ```bash
   npm install
   npm run dev
   ```
   The application will run locally at `http://localhost:5173`.

3. **Backend Setup (Express + MongoDB)**
   ```bash
   cd server
   npm install
   npm run dev
   ```

---

## 🌿 Git & Branching Workflow

1. **Create a Feature Branch**
   ```bash
   git checkout -b feat/your-feature-name
   ```

2. **Commit Message Format**
   * `feat:` Add new feature
   * `fix:` Fix existing bug
   * `docs:` Documentation updates
   * `style:` UI formatting or Tailwind refinements

3. **Push & Create Pull Request**
   ```bash
   git push origin feat/your-feature-name
   ```
